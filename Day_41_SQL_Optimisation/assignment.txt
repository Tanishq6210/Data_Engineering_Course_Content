Create Table
CREATE TABLE Employees (
    EmployeeID INT PRIMARY KEY,
    Name VARCHAR(100),
    Department VARCHAR(50),
    Salary DECIMAL(10,2),
    Age INT,
    City VARCHAR(50)
);

Question 2

SELECT *
FROM Employees
WHERE Salary > 70000;

Observe the execution plan.

Which operation is being used?
Why?
Question 3

Create an index on the Salary column.

CREATE INDEX idx_salary
ON Employees(Salary);

Run the previous query again.

Compare both execution plans.

Write three observations.

Question 4

Run the following query.

SELECT *
FROM Employees
WHERE Salary = 92000;
Is the execution plan different from Question 2?

Question 5

Run the following query.

SELECT *
FROM Employees
WHERE Salary > 10000;

Question 6

DROP INDEX idx_salary
ON Employees;

Run Question 4 again.

Compare the execution plan before and after dropping the index.
