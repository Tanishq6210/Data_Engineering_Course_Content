Tasks

Students should complete the following 10 tasks using PySpark:

Read the JSON file into a DataFrame and use printSchema() to identify the StructType, ArrayType, and MapType fields.
Flatten the nested structures and create columns for:
order_id
customer_id
customer_name
city
restaurant_name
payment_method
payment_status
Use array_contains() to find orders having the "dinner" tag and use size() to create a tag_count column.
Use element_at() to extract the device from the metadata map.
Use explode() on the items array so that each food item becomes a separate row. Extract:
item_id
item_name
category
price
quantity
Convert order_timestamp into a proper timestamp and create:
order_date
order_year
order_month
order_day
Create a new column:
item_total = price × quantity

Then remove records where item_total <= 0 or required fields are null.

Keep only orders where:
payment_status = SUCCESS

Then calculate total revenue by restaurant and order date.

Partition the final output by order_date and save it as Parquet.
Use explain(True) on your final aggregation and identify:
Where the shuffle occurs.
Which operation causes the aggregation.
Why Spark may need multiple stages for this pipeline.
