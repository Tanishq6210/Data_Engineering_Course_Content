Homework – Window Functions

This homework uses an Online Retail Store scenario instead of employees and students so that students apply the same concepts in a different context.

Database Creation
Create Products Table
CREATE TABLE products (
    product_id INT PRIMARY KEY,
    product_name VARCHAR(100),
    category VARCHAR(50),
    price DECIMAL(10,2)
);

Create Customers Table
CREATE TABLE retail_customers (
    customer_id INT PRIMARY KEY,
    customer_name VARCHAR(100),
    city VARCHAR(50),
    total_spent DECIMAL(10,2)
);

CREATE TABLE orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    product_id INT,
    quantity INT,
    order_amount DECIMAL(10,2),
    order_date DATE
);

Homework Questions
Question 1 (OVER())
Display every product along with its price and the average price of all products.

Question 2 (PARTITION BY)
Display every product along with its category and the average price within its category.

Question 3 (ORDER BY inside Window)
Assign a unique number to every product based on price from highest to lowest.

Question 4 (ROW_NUMBER + PARTITION BY)
Assign a unique number to every product within each category, ordered by price (highest first).

Question 5 (Top N Per Group)
Display the top 2 most expensive products from each category.

Question 6 (RANK)
Rank customers according to the total amount they have spent, from highest spender to lowest.
If two customers have spent the same amount, they should receive the same rank.

Question 7 (DENSE_RANK)
Rank customers according to total spending using DENSE_RANK().



Expected Concepts

Difference between RANK() and DENSE_RANK()
Question 8 (ROW_NUMBER vs RANK)

Generate three columns showing

ROW_NUMBER()
RANK()
DENSE_RANK()

for customer spending.

Observe and explain the differences.

Expected Concepts

Comparison of all three ranking functions
Question 9 (NTILE)

Divide customers into 4 equal spending groups (quartiles) based on total_spent.

Label them using NTILE(4).
