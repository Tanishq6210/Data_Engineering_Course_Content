============================================================

company.

duplicate orders, missing values, inconsistent restaurant

Your task is to design a Medallion Architecture that converts
the raw application data into business-ready data.

                         v
                  RAW → BRONZE
                         |
                         v
                  BRONZE → SILVER
                         |
                         v
                   SILVER → GOLD
                         |
                         v
                     ANALYTICS

============================================================
PART 1 — UNDERSTAND THE RAW DATA
============================================================

Create:

data/raw/food_orders.csv

Use the dataset provided at the end of this assignment.

Before writing any pipeline code, inspect the data and
identify:

- What does one row represent?
- What is the unique identifier?
- Which columns contain numeric data?
- Which columns contain dates/times?
- What data-quality problems can you identify?

Do not modify the raw file.


============================================================
PART 2 — RAW → BRONZE
============================================================

Create:

pipelines/raw_to_bronze.py

Your pipeline should:

1. Read the raw CSV using Pandas.

2. Preserve the source data with minimal transformation.

3. Save the result as:

data/bronze/food_orders.csv

The Bronze layer should remain close to the original
source data.

Do not perform business aggregations in this pipeline.

Expected flow:

Raw
 ↓
Read
 ↓
Bronze


============================================================
PART 3 — BRONZE → SILVER
============================================================

Create:

pipelines/bronze_to_silver.py

Read the Bronze dataset and create a trusted Silver dataset.

Apply appropriate data-quality rules based on the problems
you identified in Part 1.

Your Silver pipeline should:

- Remove duplicate orders.
- Handle missing values where required.
- Remove invalid order records.
- Standardize restaurant names.
- Standardize city names.
- Convert numeric columns to appropriate numeric types.
- Convert order_date to a proper date/datetime type.
- Create a new column:

delivery_time_minutes

using:

delivery_time - order_time

The final Silver dataset should contain only records that
are suitable for downstream business analysis.

Save it to:

data/silver/food_orders.csv


Expected flow:

Bronze
   ↓
Clean
   ↓
Validate
   ↓
Standardize
   ↓
Derive useful fields
   ↓
Silver


IMPORTANT:

Do not blindly apply every possible Pandas function.

Decide which transformations are actually required based
on the dataset.


============================================================
PART 4 — VERIFY THE SILVER LAYER
============================================================

After creating Silver, verify that:

- Duplicate order IDs no longer exist.
- Required fields do not contain invalid values.
- Restaurant names are standardized.
- City names are standardized.
- Numeric columns have appropriate types.
- delivery_time_minutes contains valid values.

Print the number of records:

Before Silver:
____ records

After Silver:
____ records

Briefly explain why the number of records changed.


============================================================
PART 5 — SILVER → GOLD
============================================================

Create:

pipelines/silver_to_gold.py

The food delivery company's management wants to understand
restaurant performance.

Create a Gold dataset answering:

"How is each restaurant performing?"

For every restaurant calculate:

- restaurant
- total_orders
- total_revenue
- average_order_value
- average_delivery_time


Save the result as:

data/gold/restaurant_performance.csv


Expected flow:

Silver
   ↓
Group by restaurant
   ↓
Calculate business metrics
   ↓
Gold


============================================================
PART 6 — BUSINESS REQUIREMENT
============================================================

The management team wants to identify restaurants that
need attention.

Using the Gold dataset, determine:

1. Which restaurants have the highest revenue?
2. Which restaurants have the highest average delivery time?
3. Which restaurants have the highest number of orders?

You do NOT need to create another Gold dataset.

Use the existing Gold dataset to answer these questions.

Write your observations in README.md.


============================================================
PART 7 — BUILD THE ORCHESTRATOR
============================================================

Create:

orchestrator.py

The orchestrator must execute the pipelines in this exact
order:

1. raw_to_bronze.py
2. bronze_to_silver.py
3. silver_to_gold.py

The user should be able to run the entire data pipeline
using only:

python orchestrator.py

The orchestrator should print a message when each pipeline
starts and finishes.

Example:

Starting Raw → Bronze
Raw → Bronze completed

Starting Bronze → Silver
Bronze → Silver completed

Starting Silver → Gold
Silver → Gold completed

All pipelines completed successfully!


============================================================
PART 8 — FAILURE HANDLING
============================================================

Modify the orchestrator so that if one pipeline fails,
the next pipeline does not execute.

For example:

Raw → Bronze       ✓
Bronze → Silver    ✗
Silver → Gold      SHOULD NOT RUN

The orchestrator should clearly display which pipeline
failed.
